# Asteroids

My take on the original arcade game. Made with [raylib](https://www.raylib.com/). 

## Controls

##### Left:      `rotate left`
##### Right:     `rotate right`
##### Up:        `thrust`
##### Left CTRL: `shoot`
##### Left ALT:  `hyperspace`
##### D:         `debugging display`
